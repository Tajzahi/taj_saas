# 10 — Pre-Build Checklist

Checklist ini digunakan sebelum development dimulai secara serius.

## 1. Product and Business

- [ ] Visi produk disetujui.
- [ ] Target user/persona disetujui.
- [ ] Scope full enterprise disetujui.
- [ ] Batasan non-scope atau integrasi eksternal jelas.
- [ ] Business rules utama disetujui.
- [ ] Success metrics disepakati.

## 2. Portal and Module

- [ ] Pembagian Customer Web, Karyawan Web, Owner/Admin Web disetujui.
- [ ] Customer Web flow disetujui.
- [ ] POS/Kitchen flow disetujui.
- [ ] Owner/Admin module map disetujui.
- [ ] RBAC dan role disetujui.
- [ ] Approval workflow awal disetujui.

## 3. Technical Architecture

- [ ] Stack dipilih.
- [ ] Monorepo structure disetujui.
- [ ] Backend modular boundaries disetujui.
- [ ] Database engine dipilih.
- [ ] Multi-tenant strategy diputuskan.
- [ ] Deployment environment disiapkan.
- [ ] Backup strategy disetujui.

## 4. Data and API

- [ ] ERD high-level disetujui.
- [ ] Data dictionary baseline tersedia.
- [ ] API contract baseline tersedia.
- [ ] Naming convention disetujui.
- [ ] Migration strategy disetujui.
- [ ] Seed data awal ditentukan.

## 5. Security and Compliance

- [ ] RBAC enforced backend.
- [ ] Tenant/outlet scoping rule disetujui.
- [ ] Audit log scope disetujui.
- [ ] Password/PIN/OTP security disetujui.
- [ ] Payment security rule disetujui.
- [ ] Data export permission disetujui.

## 6. UX and Design

- [ ] Sitemap 3 portal disetujui.
- [ ] Wireframe POS disetujui.
- [ ] Wireframe kitchen disetujui.
- [ ] Wireframe owner dashboard disetujui.
- [ ] Mobile customer flow disetujui.
- [ ] Design system awal dibuat.

## 7. QA and Delivery

- [ ] Test strategy disetujui.
- [ ] Critical E2E scenarios disepakati.
- [ ] Definition of Done disepakati.
- [ ] Acceptance criteria produk disetujui.
- [ ] Release gate disetujui.
- [ ] Rollback plan ditentukan.

## 8. Operational Readiness

- [ ] Monitoring tool dipilih.
- [ ] Error tracking dipilih.
- [ ] Log format disetujui.
- [ ] Backup restore drill dijadwalkan.
- [ ] Admin training plan dibuat.
- [ ] User guide plan dibuat.

## 9. Final Gate

Development besar boleh dimulai jika dokumen berikut minimal sudah signoff:

- Master Blueprint.
- Enterprise Scope and Module Map.
- Functional Requirements.
- Architecture and Tech Stack.
- Data Model.
- RBAC and Workflows.
- UI/UX Sitemap.
- API/Security/QA baseline.
- Delivery and Acceptance Plan.
